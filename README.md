# 🔐 Password Strength Checker

A web-based password strength checker built with Flask that evaluates password security in real-time and provides actionable feedback to help users create stronger passwords.

---

## 🌐 Live Demo

👉 https://password-strength-checker-1-6bqq.onrender.com

---

## 🚀 Features

- Real-time password strength evaluation  
- Strength classification (Weak / Medium / Strong)  
- Detection of common password weaknesses  
- Actionable suggestions for improving security  
- Lightweight and responsive web interface  

---

## 🛠️ Tech Stack

- **Backend:** Python (Flask)  
- **Frontend:** HTML, CSS, JavaScript  
- **Deployment:** Gunicorn + Render
